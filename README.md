# Credit Card Rewards Optimizer (Q2 2026)

A Streamlit application to identify the best credit card for specific spending categories, including automatic support for rotating 5% categories (Discover, Chase Freedom Flex, etc.).

## 🚀 Live App
Access the tool here: **[https://jakeeldercreditcardsrewards.streamlit.app/](https://jakeeldercreditcardsrewards.streamlit.app/)**

## ✨ Features
*   **Dynamic Rewards:** Automatically updates to show the correct 5% rotating categories for the current quarter (April - June 2026).
*   **Empirical Valuations:** Adjusted reward percentages based on real-world point valuations (April 2026 data).
*   **Dual-Source Data:** Fetches latest data from Google Sheets with a reliable local CSV fallback for offline/emergency use.
*   **Mobile Optimized:** Interface adapts for quick use at checkout.

## 🛠️ Tech Stack
*   **Frontend/Backend:** Python + Streamlit
*   **Data Handling:** Pandas
*   **Source Data:** Google Sheets (Primary) & Local CSVs (Fallback)
